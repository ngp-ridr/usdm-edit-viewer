# Deferred

Work this app has decided **not** to do yet, with the reason and what would
change the decision. A line here is a decision, not a TODO: it exists so the
next reader does not re-open a question that was already answered, and so a
measurement that made something acceptable can be re-checked when it stops
being true.

Format: a heading per item, then what it is, why it is deferred, and what would
un-defer it.
